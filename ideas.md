## Ideia 1: "Confiança Institucional" — Swiss Corporate Design

### Design Movement
Inspirado no International Typographic Style (Swiss Design) aplicado ao setor farmacêutico, com rigor tipográfico e clareza informacional que transmite credibilidade corporativa.

### Core Principles
1. **Hierarquia tipográfica rígida** — cada nível de informação tem peso visual distinto
2. **Grid modular assimétrico** — colunas desiguais que criam tensão visual controlada
3. **Espaço negativo como elemento ativo** — áreas vazias que respiram e direcionam o olhar
4. **Fotografia documental** — imagens reais de farmácia, não ilustrações genéricas

### Color Philosophy
Paleta fiel ao manual da marca: Azul Maestra (#2D4260) como cor dominante transmitindo solidez e confiança. Vermelho (#C20E1A) usado cirurgicamente como cor de ação e urgência (CTAs, destaques de desconto). Branco como espaço de respiro. Cinza (#585857) para texto secundário. O azul complementar (#007AB1) para elementos informativos e ícones.

### Layout Paradigm
Grid assimétrico de 8 colunas com seções que alternam entre full-bleed e contenção. Hero com split layout (texto à esquerda 60%, imagem à direita 40%). Seções de benefícios em cards com layout de magazine (tamanhos variados). Endereços em layout de mapa interativo.

### Signature Elements
1. Barra vermelha superior fina como elemento de marca (conforme manual)
2. Números grandes em destaque (15%, 75%, 30+ anos) como âncoras visuais
3. Ícones lineares em azul complementar para serviços

### Interaction Philosophy
Scroll suave com revelação progressiva. Cards de benefícios com hover que expande informação. Números animados (counter) ao entrar na viewport.

### Animation
Fade-in sutil de baixo para cima nas seções. Counters animados nos números de destaque. Transições suaves de 300ms em hovers. Parallax leve no hero.

### Typography System
DIN (substituto web: "DM Sans" ou "Source Sans 3") para manter a essência da PFDinTextPro do manual. Títulos em peso 700/800, subtítulos em 500, corpo em 400. Tamanhos: H1 4rem, H2 2.5rem, H3 1.5rem, body 1rem.

## Ideia 2: "Cuidado Humanizado" — Organic Warmth Design

### Design Movement
Biophilic Design aplicado ao contexto farmacêutico — formas orgânicas, curvas suaves e elementos que evocam cuidado, saúde e proximidade humana.

### Core Principles
1. **Formas orgânicas** — bordas arredondadas, blobs, ondulações entre seções
2. **Calor humano** — fotografia de pessoas reais, sorrisos, interação
3. **Fluidez narrativa** — a página conta uma história de parceria, não apenas lista benefícios
4. **Acessibilidade emocional** — linguagem e design que acolhem

### Color Philosophy
Azul Maestra (#2D4260) como base de confiança, mas suavizado com tons de azul claro (#E8F0F8) nos fundos. Vermelho (#C20E1A) transformado em acentos quentes e acolhedores. Introdução de um tom off-white creme (#F9F6F1) para fundos que evitam a frieza do branco puro. Verde sutil para elementos de saúde.

### Layout Paradigm
Seções com divisores ondulados (wave dividers) entre elas. Hero com imagem full-width e overlay gradiente. Cards flutuantes com sombras suaves. Layout em "S" — alternando conteúdo esquerda/direita para guiar o olhar naturalmente.

### Signature Elements
1. Wave dividers entre seções com as cores da marca
2. Ícones com estilo "filled" arredondado dentro de círculos coloridos
3. Badges de destaque com cantos pill-shaped para benefícios-chave

### Interaction Philosophy
Scroll storytelling — cada seção revela uma parte da proposta de valor. Micro-interações nos ícones de serviço (pulse, bounce). CTA flutuante que acompanha o scroll.

### Animation
Entrada com slide suave e fade. Ícones com animação de pulse ao hover. Wave dividers com animação sutil de ondulação. Stagger animation nos cards de serviços.

### Typography System
"Nunito" para títulos (arredondada, amigável) + "Open Sans" para corpo (legível, profissional). Títulos em 700/800, corpo em 400/500. Uso generoso de line-height para respiração.

## Ideia 3: "Precisão Farmacêutica" — Editorial Moderno

### Design Movement
Editorial Design contemporâneo — inspirado em revistas corporativas de alto padrão, com tipografia expressiva, uso dramático de escala e composição fotográfica editorial.

### Core Principles
1. **Contraste de escala** — números e títulos gigantes contrastando com texto fino
2. **Composição editorial** — layout inspirado em spreads de revista, não em templates web
3. **Dados como design** — estatísticas e números são os protagonistas visuais
4. **Sofisticação contida** — elegância sem exagero, profissionalismo sem frieza

### Color Philosophy
Azul Maestra (#2D4260) dominante em blocos sólidos de cor. Vermelho (#C20E1A) exclusivamente para dados numéricos de impacto e CTAs. Fundo alternando entre branco puro e azul escuro para criar ritmo dramático. Azul complementar (#007AB1) para links e elementos interativos.

### Layout Paradigm
Layout editorial com seções de altura total (100vh) para os pontos-chave. Grid de 12 colunas com elementos que quebram o grid intencionalmente. Hero com tipografia oversized. Seção de benefícios como "infográfico editorial" com números gigantes. Rodapé com endereços em grid compacto e elegante.

### Signature Elements
1. Números em escala oversized (ex: "15%" em 8rem) com fonte condensada
2. Blocos de cor sólida azul escuro com texto branco para seções de destaque
3. Linha vermelha fina como separador e elemento de marca

### Interaction Philosophy
Scroll-triggered reveals com timing preciso. Hover states com underline animado. Transições de cor suaves entre seções claras e escuras.

### Animation
Clip-path reveals nas seções. Números com animação de contagem. Text reveal com máscara. Transições de background-color suaves no scroll. Parallax controlado em imagens.

### Typography System
"Space Grotesk" para títulos (geométrica, moderna, com personalidade) + "DM Sans" para corpo (limpa, profissional). Títulos em 700, corpo em 400. H1 em 5rem+, números de destaque em 8rem+. Tracking apertado em títulos grandes.

## Decisão: Ideia 3 — "Precisão Farmacêutica" (Editorial Moderno)

Escolho a Ideia 3 por combinar sofisticação corporativa com impacto visual forte, ideal para uma proposta B2B que precisa impressionar decisores. O uso editorial de números grandes e blocos de cor cria uma narrativa visual persuasiva que destaca os benefícios-chave do convênio (15% desconto, até 75%, 30+ anos, 60 dias prazo).
